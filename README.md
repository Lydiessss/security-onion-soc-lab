
# Security Onion SOC Lab

## Objectif
Mettre en place un laboratoire de détection d’intrusion (SOC) avec Security Onion afin de surveiller, analyser et détecter des activités suspectes sur un réseau.

## Architecture du laboratoire
- Machine attaquante : Kali Linux
- Machine cible : Ubuntu
- Machine de supervision : Security Onion

## Outils utilisés
- Security Onion
- Suricata
- Zeek
- Wireshark
- VirtualBox

##  Scénarios de test
- Ping entre machines
- Scan de ports
- Simulation d’attaques réseau
- Détection des attaques 

##  Résultats
Security Onion a détecté les activités suspectes et généré des alertes visibles dans le dashboard SOC.

##  Conclusion
Ce laboratoire permet de comprendre le fonctionnement d’un système de détection d’intrusion en environnement réel.
